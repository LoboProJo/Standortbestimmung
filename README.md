# Standortbestimmung

 Wenn man das Programm strartet hat man eine übersicht der Funktionen. Wenn man nummer 1 auswählt werden alle regrestrierten Fahrzeuge angezeigt mit Kennzeichen und Sitzplplatz kapazität. Wenn man die zweite Auswahl, nimmt kann man entweder ein Fahrzeug mieten oder eines zurückbringen. Wenn man 0 drückt beendet man das Programm.
